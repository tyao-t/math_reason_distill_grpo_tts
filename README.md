# Distillation, GRPO, and Test-Time Scaling for Math Reasoning

Intended for CS5260 (Neural Networks and Deep Learning II).

This is a technically substantive project. For a full walkthrough of
the work — distillation (SFT) from a 235B teacher, GRPO reinforcement
learning, and test-time scaling (TTS) for a 0.6B math-reasoning model
— please read either `project_report_en.txt` or
`project_report_zh.txt`; the two are the same report in different
languages.

For more technical, foundational modeling-architecture and
pre/post-training implementation details, please review
https://github.com/tyao-t/torch-ray-models, which is also a highly
technically substantive project.
